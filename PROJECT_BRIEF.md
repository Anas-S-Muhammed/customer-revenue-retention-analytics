# Customer Revenue and Retention Analytics

## Business context

This project analyzes customer purchases for an e-commerce business.

## Business problem

The business wants to understand revenue performance, customer retention, repeat purchasing, and product performance.

## Main stakeholder

The stakeholder is the e-commerce manager or business owner.

## Questions this project will answer

1. What is the monthly revenue trend?
2. Which products and categories generate the most revenue?
3. What is the average order value?
4. What percentage of customers make repeat purchases?
5. How does customer retention change by acquisition month?
6. Which customer segments generate the most revenue?
7. Which products or categories may need attention?

## Planned tools

- PostgreSQL
- SQL
- Python
- Pandas
- Matplotlib or Seaborn
- Power BI, Tableau, or Streamlit
- Git and GitHub

## Expected outputs

- Clean relational database
- SQL analysis queries
- Data-quality checks
- Customer retention analysis
- Dashboard
- Written business recommendations
- Reproducible README

## Important limitation

The analysis will describe patterns in the selected dataset. It will not automatically prove that one business decision caused another outcome.
